# پروژه تشخیص ارقام دست‌نویس (Handwritten Digit Recognition)

## ۱. تعریف مسئله و چارچوب PEAS

هدف این پروژه طراحی یک عامل هوشمند برای تشخیص ارقام دست‌نویس از روی تصاویر و طبقه‌بندی آن‌ها در یکی از ده کلاس صفر تا نه (0–9) با استفاده از روش‌های یادگیری ماشین است.

| مؤلفه | شرح |
| -------------------------------------- | ------------------------------------------------------------------------------------ |
| **معیار عملکرد (Performance Measure)** | دقت تشخیص (Accuracy)، معیارهای Precision، Recall و F1-score، نرخ خطا و زمان پیش‌بینی |
| **محیط (Environment)** | مجموعه تصاویر ارقام دست‌نویس |
| **عملگرها (Actuators)** | ارائه رقم تشخیص‌داده‌شده و نمایش امتیاز یا احتمال تعلق تصویر به هر کلاس |
| **حسگرها (Sensors)** | دریافت تصویر ورودی از فایل، مجموعه‌داده یا دوربین و دسترسی به مقادیر پیکسل‌های آن |

## ۲. مشخصات محیط پروژه

| ویژگی محیط | نوع محیط | توضیح |
| ---------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------- |
| **کامل / جزئی (Fully / Partially Observable)** | کاملاً قابل مشاهده | تمام پیکسل‌های تصویر ورودی در دسترس عامل قرار دارند. |
| **تک / چندعامله (Single-Agent / Multi-Agent)** | تک‌عامله | یک عامل هوشمند وظیفه تشخیص رقم را انجام می‌دهد. |
| **قطعی / تصادفی (Deterministic / Stochastic)** | تصادفی | تنوع دست‌خط و ابهام تصاویر می‌تواند موجب عدم قطعیت در تشخیص شود. |
| **اپیزودیک / ترتیبی (Episodic / Sequential)** | اپیزودیک | هر تصویر به‌طور مستقل پردازش می‌شود و نتیجه آن بر پردازش تصاویر دیگر تأثیر نمی‌گذارد. |
| **ایستا / پویا (Static / Dynamic)** | ایستا | تصویر در طول فرایند تشخیص ثابت باقی می‌ماند. |
| **گسسته / پیوسته (Discrete / Continuous)** | گسسته | خروجی نهایی عامل یکی از ده کلاس مشخص، از صفر تا نه، است. |
