# How

How the work in this step was produced.

## Tools and AI assistance

- ChatGPT used for content creation
- [Arena.ai](http://Arena.ai) used for GitHub connection
- `agent.py` is being created with the help of Grok 4.6 and Argon 4, based on the class code

## Data

No external download: the digits come from the `load_digits` dataset shipped with
scikit-learn (8×8 greyscale images, 1797 samples, 64 pixel features, 10 classes).
Because the dataset is built in, the script runs offline and results are reproducible
from the seeds in the code.

## Dependencies

See [`../requirements.txt`](../requirements.txt) — NumPy, pandas, Matplotlib, scikit-learn.

## Reproducing the results

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python agent.py
```

Expected order of results: `random` ≈ 10 % (chance level for ten classes),
`knn` ≈ 98.6 %, `logreg` ≈ 96.8 % mean test accuracy over 100 stratified splits.
The figures and animations are generated by the script itself; no numbers are typed in
by hand.
