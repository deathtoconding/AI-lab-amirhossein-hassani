# Evaluation Metrics, Risks and Reporting Protocol

> **Summary (English).** §1 defines the evaluation metrics used for the digit agent
> (accuracy, macro-F1, per-class precision/recall, confusion matrix, inference latency).
> §2 lists risks and limitations with mitigations and how each is assessed.
> §3 is the protocol that must be followed when reporting results (dataset, splits, model,
> metrics, error analysis, speed, reproducibility). The notes are written in Persian.

# معیارهای ارزیابی، ریسک‌ها و پروتکل گزارش

## ۱. معیارهای ارزیابی مدل

| معیار | تعریف علمی | کاربرد و محدودیت |
|---|---|---|
| **Accuracy** | نسبت پیش‌بینی‌های صحیح به کل نمونه‌های آزمون | معیار کلی عملکرد؛ ممکن است ضعف مدل در یک کلاس را پنهان کند. |
| **Macro-F1** | میانگین حسابی F1 هر کلاس با وزن برابر | ارزیابی متوازن عملکرد روی هر ۱۰ رقم، مستقل از فراوانی کلاس‌ها |
| **Precision** | نسبت پیش‌بینی‌های صحیح یک کلاس به تمام پیش‌بینی‌های منتسب به آن کلاس | مشخص می‌کند چند مورد از پیش‌بینی‌های یک رقم صحیح بوده‌اند. |
| **Recall** | نسبت نمونه‌های صحیح یک کلاس که مدل آن‌ها را درست شناسایی کرده است | مشخص می‌کند چه سهمی از نمونه‌های واقعی هر رقم شناسایی شده‌اند. |
| **Confusion Matrix** | جدول تعداد پیش‌بینی‌های واقعی در برابر کلاس‌های پیش‌بینی‌شده | شناسایی جفت‌ارقام مستعد اشتباه، مانند ۳ و ۸ |
| **Inference Latency** | مدت‌زمان لازم برای تولید پیش‌بینی برای یک ورودی | سنجش سرعت استنتاج؛ باید سخت‌افزار، اندازه دسته و روش اندازه‌گیری مشخص باشند. |

## ۲. ریسک‌ها، محدودیت‌ها و راهکارهای کاهش آن‌ها

| ریسک یا محدودیت | پیامد احتمالی | راهکار کاهش ریسک | روش ارزیابی |
|---|---|---|---|
| **تنوع دست‌خط** | کاهش دقت روی سبک‌های نوشتاری دیده‌نشده | استفاده از داده‌های متنوع و افزایش داده با تبدیل‌های واقع‌گرایانه | ارزیابی روی نمونه‌هایی با سبک‌های متفاوت |
| **کیفیت پایین تصویر** | از دست رفتن جزئیات و افزایش خطای طبقه‌بندی | بررسی کیفیت ورودی و اعمال پیش‌پردازش کنترل‌شده | مقایسه عملکرد در سطوح مختلف نویز و وضوح |
| **بیش‌برازش (Overfitting)** | عملکرد بالا روی داده‌های آموزش و ضعیف‌تر روی داده‌های جدید | تنظیم منظم‌سازی، توقف زودهنگام و انتخاب مدل با مجموعه اعتبارسنجی | مقایسه عملکرد آموزش و اعتبارسنجی و ارزیابی نهایی روی آزمون مستقل |
| **عدم توازن کلاس‌ها** | عملکرد ضعیف‌تر روی ارقام کم‌نمونه | بررسی توزیع کلاس‌ها و استفاده متناسب از وزن‌دهی یا نمونه‌برداری مجدد | گزارش Precision، Recall و F1 برای هر کلاس |
| **شباهت ظاهری ارقام** | اشتباه گرفتن ارقام با شکل‌های مشابه | تحلیل خطاها و بررسی نمونه‌های اشتباه طبقه‌بندی‌شده | تحلیل ماتریس درهم‌ریختگی و نمونه‌های خطا |
| **تفاوت توزیع داده‌ها (Distribution Shift)** | افت عملکرد روی داده‌های واقعی متفاوت از داده‌های آموزش | آزمون روی داده‌های نماینده محیط کاربرد و بازبینی دوره‌ای عملکرد | مقایسه معیارها میان مجموعه آزمون و داده‌های محیط واقعی |
| **ناسازگاری پیش‌پردازش** | تغییر ناخواسته توزیع ورودی مدل در زمان استنتاج | استفاده از خط لوله پیش‌پردازش یکسان در آموزش و پیش‌بینی | آزمون سازگاری اندازه، کانال رنگی، مقیاس پیکسل و نرمال‌سازی |
| **نشت داده (Data Leakage)** | برآورد غیرواقعی و بیش‌ازحد خوش‌بینانه از عملکرد | جداسازی صحیح آموزش، اعتبارسنجی و آزمون پیش از انتخاب مدل | بررسی هم‌پوشانی نمونه‌ها و اطمینان از استقلال مجموعه آزمون |
| **عدم قطعیت نتایج** | احتمال تفسیر نادرست اختلاف‌های کوچک در عملکرد مدل‌ها | گزارش تعداد نمونه‌ها و فاصله اطمینان، در صورت امکان | محاسبه فاصله اطمینان با روش آماری مناسب |

## ۳. پروتکل گزارش نتایج

| مؤلفه | الزام گزارش |
|---|---|
| **مجموعه داده** | نام، نسخه، تعداد نمونه‌ها و توزیع کلاس‌ها |
| **تقسیم داده‌ها** | تعداد نمونه‌های آموزش، اعتبارسنجی و آزمون و روش تقسیم |
| **مدل** | معماری، ابرپارامترهای اصلی و روش آموزش |
| **معیارهای عملکرد** | Accuracy، Macro-F1 و نتایج هر کلاس |
| **تحلیل خطا** | ماتریس درهم‌ریختگی و نمونه‌های خطای شاخص |
| **سرعت اجرا** | سخت‌افزار، اندازه دسته و روش اندازه‌گیری تأخیر |
| **قابلیت بازتولید** | بذر تصادفی، نسخه کتابخانه‌ها و تنظیمات آزمایش |
| **نتایج نهایی** | مقادیر اندازه‌گیری‌شده، بدون درج اعداد تخمینی به‌عنوان نتایج واقعی |
